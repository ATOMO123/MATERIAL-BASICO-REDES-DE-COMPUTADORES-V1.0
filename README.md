## 📖 O QUE ENCONTRAS AQUI

Este repositório reúne o material essencial para quem quer aprender Redes de Computadores do zero, com uma abordagem prática e progressiva.

| Conteúdo | Descrição |
|----------|-----------|
| Fundamentos de Redes | Conceitos, componentes, tipos de redes e topologias |
| Modelo OSI e TCP/IP | Explicação das camadas, protocolos e encapsulamento |
| Meios de Transmissão | Cabo coaxial, par trançado, fibra ótica |
| Equipamentos de Rede | Hub, switch, router, access point |
| Endereçamento IP | IPv4, sub-redes, VLSM, cálculo de hosts |
| Exercícios Práticos | Atividades para consolidar a teoria |
